# IdeaVault - Quick Notes Taking App

A clean and lightweight web-based notes-taking application built with HTML, CSS, and JavaScript.

## Live Demo
You can check out the live version of the application here:
[View Live Site](https://mrrao117.github.io/IdeaVault/)

## Features
- Simple and intuitive user interface
- Create, edit, and organize notes quickly
- Uses local storage for storing notes
- Fully responsive design
